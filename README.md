# CodeAlpha Portfolio

A responsive personal portfolio website for introducing Sameer Ahmad, highlighting education and technical skills, and showcasing selected projects.

## Features

- Single-page navigation to About, Education, Skills, Projects, and Contact sections
- Responsive layout for desktop and mobile screens
- Project cards with technology details and a link to the Image Gallery repository
- Built with plain HTML, CSS, and JavaScript; no build tools or dependencies required

## Project structure

```text
.
├── index.html
├── style.css
├── script.js
└── README.md
```

## Run locally

Open `index.html` in a web browser. No installation or build step is needed.

## Customize

Update the content in `index.html` with your current details and replace the example email address with a contact email. Adjust colors, spacing, and responsive styles in `style.css`.
